# Balkon Çamaşırının Uluslararası İltica Başvurusu

> **Resmi uyarı:** Bu depo bir şaka değildir. Rüzgâr da şaka değildir. Çamaşır ipi ise uluslararası bir sınırdır.

## Bu yazılım ne yapar?

Balkonunuzdaki ıslak bir vatandaşı (teknik adı: *kumaş*) Cenevre formatında mülteci statüsüne kavuşturur. Çalışır. Neden çalıştığını sormayın. Soru sormak geri gönderme sebebidir.

## Kurulum

```bash
python3 iltica.py
python3 iltica.py --parca "sol çorap"
python3 iltica.py --gizli
```

Üçüncü komut sınıflandırılmış eki açar. Orada parti yok, sadece kumaş hukuku vardır. Görmeyen görmemiş sayılır.

## Akademik gerekçe

1. Rüzgâr, önceden bildirim yapmadan egemenlik kullanır.
2. Mandal, tanık olarak yeterince tarafsız değildir; çünkü kendisi de asılıdır.
3. Kuruma süresi, geri gönderme yasağının doğal süresidir.
4. Komşu balkon üçüncü ülkedir. Kapı zili vize değildir.
